# Home Robotics Arena Scene

This repo accomodates the Arena scene (`isaac_worlds/Arena.usd`) in IsaacSim 5.0, utilized usd files, and command scripts which provide:
* Table elevating
* Fridge, oven, and dishwasher door opening

Also it has a separate scene (`isaac_worlds/Arena_wall_upd.usd`) with pick and place corner cloned directly from the benchmark scene, additionally involving:
* Franka wrist camera
* Side camera
* Pick and place assets
and the action graphs for all of these.
